# 2.0.1
- Цепочки серверов: трафик теперь можно пустить через другой сервер, если основной не работает
- DNS из профиля: BEAM может использовать DNS-серверы, которые выдал ваш VPN-провайдер
- Hysteria2: можно подключаться к серверам с самоподписанным сертификатом и без сертификата, BEAM предупредит, что это небезопасно
- Пинг: результат показывается сразу, как только приходит, а не после окончания всех замеров
- Исправлена ошибка, из-за которой вместо интерфейса BEAM открывалось чёрное окно
- Флаги стран теперь работают без доступа в интернет
- Исправлено автоподключение по Wi-Fi: раньше BEAM не мог автоматически создать адаптер и приходилось переподключаться вручную
- Конфигурации и аналитика: интерфейс немного доработан под стандарты Material 3
